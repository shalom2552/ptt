# CLAUDE.md

`docs/conventions.md` is how the tools behave. This is how to work on them.

## Writing

Short, plain, human. No em dashes, emojis, AI buzzwords.
Commits are one line, `type(scope): 3-8 words`. No body.
Never sign the work: no co-author, no "generated by", no tool names, in
commits or PRs.
Rationale goes in `docs/`, not history.

## Comments

Prefer none. Add one only where the code cannot say it itself, then keep it
to a line.
Describe the code as it stands. Never what changed or why it changed.
Strip comments from any block copied out of another file.

## Code

Strict YAGNI. Only what was asked.
POSIX shell where it costs nothing, so this ports past Arch and bash.
Root `ptt` is a shim. Scripts in `src/`, shared libs in `src/lib/`, data in
`share/`.
Each bash script sets `PTT_ROOT` from its own location. No hardcoded repo
paths.
Source `src/lib/log.sh` and `src/lib/ui.sh`, never copy them. Every terminal
line carries a level.

## Testing

Mic work is the user's. Never start a dictation session: `WTYPE` types into
whatever window has focus.

## Git

Read only. Ask before staging, committing, or rewriting.
`~/.config/hypr` is a separate repo: edit, `hyprctl reload`, never stage.
