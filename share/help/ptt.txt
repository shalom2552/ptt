ptt - push to talk voice typing

usage: ptt <command> [options]

commands:
  begin        start dictating
  end          stop dictating, the text is typed
  install      install the stack, or reconfigure it
  uninstall    remove the packages, the model, and the symlinks

options:
  -s, --step   show each command and confirm it before it runs
  -h, --help   show this help

examples:
  ptt install
  ptt install --step
  ptt uninstall

begin and end are what a keybind calls. You normally only run install and
uninstall by hand.
