ptt - push to talk voice typing

usage: ptt <command> [options]

commands:
  begin        start dictating
  end          stop dictating
  install      install the stack, or reconfigure it
  uninstall    remove the engine, the models, and the symlinks

options:
  -s, --step   show each command and confirm it, install and uninstall
  -m, --model  change the speech model, install only
  -h, --help   show this help

examples:
  ptt install
  ptt install --step
  ptt install --model
  ptt uninstall

begin is called by a keybind. install and uninstall are run by hand.
